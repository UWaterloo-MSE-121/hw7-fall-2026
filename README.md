# Homework 7

Please **fork** this repository to get started. Once forked, you may create a GitHub Codespace using the green **"Code"** button to begin your work.

The homework instructions are posted with the other MSE 121 homework. This repository holds the files you start from:

- `cipher.py`: where you write your `translate` function and your program. The start of `translate` checks its arguments; leave that code as it is.
- `test_translate1.py`, `test_translate2.py`, `test_translate3.py`: the tests for steps 1, 2 and 3 of `translate`.
- `test_cipher.py`: where you write your tests of the whole program.
